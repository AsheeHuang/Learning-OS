# Learning OS

Learning OS is a Markdown-native protocol for durable, agent-guided learning in an Obsidian workspace. It separates exposure from evidence so a future agent can resume both the learning state and the reason for it.

## Language

**Self-check**:
A formative lesson question used for immediate learner reflection. It does not change topic status or establish mastery.

**Assessment**:
A formal validation session that records learner responses, feedback, evidence, and per-topic outcomes. It is the only artifact that can establish mastery.

**Topic outcome**:
The qualitative assessment result for one selected lesson or note: `strong`, `partial`, or `weak`.
_Avoid_: Score, confidence

**Remediation follow-up**:
One bounded question asked after corrective feedback to test whether the learner can repair a demonstrated gap. Success after remediation is prompted understanding, not independent mastery.

**Knowledge gap**:
An explicit absence of understanding, including an `I don't know` response. It is distinct from a misconception or incorrect guess.

**Current status**:
The durable learning state stored only in `PROGRESS.md`.
_Avoid_: Assessment status, completion state

**Assessment lifecycle**:
The durable execution state of an assessment artifact: `in-progress`, `complete`, or `abandoned`. It does not represent learner understanding.
