# Mission: Operating Systems

## Why

Understand the operating-system concepts that explain how application code becomes running work on real hardware.

## Current Level

Comfortable writing application code, but unfamiliar with kernel abstractions and resource management.

## Target Level

Explain core operating-system abstractions, reason about their trade-offs, and connect them to everyday software behavior.

## Desired Outcomes

- Explain processes, threads, scheduling, virtual memory, and synchronization.
- Diagnose common concurrency and memory misconceptions.
- Read introductory operating-system material independently.

## Success Criteria

Apply the core concepts to unfamiliar scenarios and explain the reasoning without relying on memorized definitions.

## Constraints

Study in short sessions and prefer concrete examples before implementation detail.

## Out of Scope

Kernel development, device-driver implementation, and architecture-specific optimization.
