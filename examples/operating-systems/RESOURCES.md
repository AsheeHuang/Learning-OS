# Operating Systems Resources

## Knowledge

- [Book: Operating Systems: Three Easy Pieces](https://pages.cs.wisc.edu/~remzi/OSTEP/)
  A free, widely used university text organized around virtualization, concurrency, and persistence. Use for: processes, scheduling, virtual memory, concurrency, and file systems.
- [Documentation: Linux Kernel Documentation](https://docs.kernel.org/)
  Primary documentation maintained with the Linux kernel. Use for: Linux-specific behavior and implementation details.

## Further Reading

- [Book: The Linux Programming Interface](https://man7.org/tlpi/)
  A detailed reference for Linux and UNIX system programming. Use for: processes, threads, signals, memory mappings, and file I/O.
- [Manual: Linux man-pages project](https://www.kernel.org/doc/man-pages/)
  Primary reference documentation for Linux system calls and interfaces. Use for: checking exact API semantics.
