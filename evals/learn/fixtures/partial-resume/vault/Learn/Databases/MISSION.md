# Mission: Databases

## Why

Design reliable data-intensive applications and diagnose production database behavior.

## Current Level

Comfortable using SQL through application frameworks, but unfamiliar with database internals.

## Target Level

Reason about transactions, indexes, query plans, and storage trade-offs.

## Desired Outcomes

Explain database behavior and diagnose common production problems.

## Success Criteria

Apply database concepts to unfamiliar schema, concurrency, and performance scenarios.

## Constraints

Thirty-minute study sessions with concrete examples.

## Out of Scope

Implementing a database engine.
