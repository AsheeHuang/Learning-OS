# Mission: Operating Systems

## Why

Understand how applications interact with operating systems.

## Current Level

Backend engineer with no systems background.

## Target Level

Reason about unfamiliar production behavior.

## Desired Outcomes

Explain and apply process, thread, and context-switch concepts.

## Success Criteria

Transfer the concepts to new failure and performance scenarios.

## Constraints

Short sessions.

## Out of Scope

Kernel development.
